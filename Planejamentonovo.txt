🧩 Fase 1: Variáveis

Objetivo de aprendizagem:
Entender o que é uma variável e como guardar informações ou estados.

Cenário narrativo:
O pato quer conhecer o jogador e aprender a guardar dados importantes, como o nome dele e o estado do pote.

Desafio:
O jogador deve registrar informações e definir variáveis de estado.

Lacunas:

Perguntar: "Qual é o seu nome?"
Quando o jogador responder, eu devo: _____________ (cumprimentar ele pelo nome)

Depois disso, o jogador define:
pote = _____________ (vazio ou cheio)




SUB FASE 1: TIPOS DE VARIAVEIS,
O pato aprende que existem diferentes tipos de variáveis para guardar diferentes tipos de informações.

LACUNAS:
PARA REPRESENTAR NUMEROS USAMOS: _____________ (variável numérica)
PARA REPRESENTAR PALAVRAS USAMOS: _____________ (variável de texto)
PARA REPRESENTAR VERDADEIRO OU FALSO USAMOS: _____________ (variável booleana)


SUB FASE 2: VARIÁVEIS DE ESTADO,    
O pato aprende que variáveis podem guardar o estado atual de algo, como o estado do pote.
LACUNAS:
pote = _____________ (vazio ou cheio)
cor do pato = _____________ (amarelo, verde, etc.)

SUB FASE 3: CLASSIFICAÇÃO DE VARIAVEIS,
O pato vê tipos de variaveis e precisa classificar as variáveis que ele tem.
LACUNAS:
______ a = 5 (inteiro)
______ b = "Olá" (texto)
______ c = True (booleano)

sub fase 4: Juntando tudo,
O pato precisa usar variáveis para criar uma história interativa,, onde ele conta uma história e o jogador responde, e o pato guarda as respostas em variáveis para usar depois.
paginas_lidas = 5 (inteir))



Conceito-chave:
Variáveis armazenam informações que mudam com o tempo.

🔀 Fase 2: Condicionais (If / Else)

Objetivo de aprendizagem:
Compreender como tomar decisões baseadas em condições lógicas.

Cenário narrativo:
O pato está com fome, mas o pote pode estar vazio.
O jogador deve decidir o que fazer com base nesse estado.

Desafio:
Criar uma estrutura condicional para decidir a ação do pato.

Lacunas:

Se o pote estiver VAZIO:
    _____________ (encher o pote)
SENÃO:
    _____________ (comer)


Conceito-chave:
Condicionais permitem que o jogo tome decisões diferentes conforme o estado das variáveis.

🔁 Fase 3: Loops (Repetições)

Objetivo de aprendizagem:
Entender como repetir ações automaticamente até uma condição mudar.

Cenário narrativo:
O pato começou a comer, mas precisamos parar quando a ração acabar.

Desafio:
Criar um loop que faça o pato comer até o pote ficar vazio.

Lacunas:

Enquanto o pote não estiver VAZIO:
    _____________ (comer)


Conceito-chave:
Loops fazem ações se repetirem até uma condição ser satisfeita.

⚡ Fase 4: Eventos e Interações

Objetivo de aprendizagem:
Aprender a reagir a acontecimentos no jogo (ações do jogador ou do ambiente).

Cenário narrativo:
O pato está dormindo, mas alguém liga a luz do quarto.

Desafio:
Programar uma reação para o evento “luz ligada”.

Lacunas:

Quando a luz for ligada:
    _____________ (acordar o pato)


Conceito-chave:
Eventos disparam reações automáticas — o código “ouve” e reage.

🛌 Fase 5: Funções (Rotinas Reutilizáveis)

Objetivo de aprendizagem:
Entender como agrupar várias ações em uma função para simplificar o código.

Cenário narrativo:
O pato quer facilitar sua rotina de dormir. Ele vai criar uma função “dormir”.

Desafio:
Transformar uma sequência longa em uma única função reutilizável.

Lacunas:

(apagar a luz) -> (ir até a cama) -> (deitar) -> (se cobrir)

Função dormir():
    apagar a luz
    ir até a cama
    deitar
    se cobrir

Quando o pato quiser descansar, ele deve: _____________ (chamar a função dormir)


Conceito-chave:
Funções permitem reutilizar e organizar código, evitando repetição.
